# viaPhoton

> viaPhoton is a fiber optic connectivity manufacturer headquartered in Naperville, Illinois,
> founded in 2020. It designs and builds high-density fiber solutions for hyperscale and enterprise
> data centers, 5G and broadband access networks, and AI network fabrics, produced in a domestic
> "micro-factory" model. viaPhoton does not operate a public API, SDK, or developer program.

This file is generated by API Evangelist from its public profile of viaPhoton. It is not published
by viaPhoton and is not served from viaphoton.com.

## What viaPhoton makes

- Inside Plant: fiber trunks, fiber arrays, patch cords, MPO/MTP connectivity, structured cabling
  for data centers
- Outside Plant: outdoor fiber jumpers, fiber drop cables, outdoor fiber trunks for broadband and
  5G access networks

## Code

- [GitHub organization](https://github.com/viaPhoton): four public repositories. Two (QReader,
  qrdet) are forks of third-party QR-detection projects. model-zoo holds ML model weights.
  PolarityExtractor is a first-party internal web app that extracts fiber-optic polarity maps from
  engineering drawings. None is a client library and none wraps a viaPhoton API.

## API status

- **No public API.** As of 2026-09-02 viaPhoton publishes no OpenAPI, AsyncAPI, GraphQL SDL,
  Postman collection, MCP server, A2A agent card, developer portal, API reference, or SDK.
- One first-party API host exists — `https://pp-api.viaphoton.com`, the Node/Express backend of the
  product configurator — but it is an application backend, not a developer product: no reference,
  no specification, no discovery documents, and access keyed from the configurator page.
- Machine-readable discovery probed and missed on every host: `/.well-known/security.txt`,
  `/openid-configuration`, `/oauth-authorization-server`, `/oauth-protected-resource`,
  `/api-catalog`, `/ai-plugin.json`, `/agent-card.json`, `/agent.json`, `/openapi.json`,
  `/swagger.json`, `/graphql`, `/llms.txt`.
- Note for crawlers: `viaphoton.com` sits behind a SiteGround anti-bot interstitial that answers
  HTTP 202 with a meta-refresh challenge for every path, including `/robots.txt` and
  `/sitemap.xml`, regardless of user agent.
